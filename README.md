An entry for [The Worst App Idea Ever Pitched](https://make.fun/competitions/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23) on make.fun.

`main.py` writes one sentence — at most 240 characters — pitching the worst,
most useless app idea imaginable: a product that sounds real, a founder who
sounds certain, and a function nobody on earth needs.

> SnackTrack Pro uses AI to tell you the exact second your leftovers become
> leftovers, so busy professionals never again wonder whether the sandwich
> they just made is technically a leftover yet.

## Run it

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set). No trailing newline, mode `0644`, deterministic:
running it twice produces byte-identical output.
